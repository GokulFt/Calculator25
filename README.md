## Getting Started

🚀 Just Launched My Custom Calculator App Built with Flutter! 📱

Proud to share a new mini project I’ve developed — a clean, intuitive Calculator App using Flutter.

🔹 Key Features :

• Basic operations : Addition, Subtraction, Multiplication & Division

• +/- button : This button to toggle between positive and negative values

• % button: This button for quick percentage calculations

• AC Button : It clears the current value and full history

• C  Button :  It clears only the current value

• < Button : It acts as a backspace to delete digits one by one

Clear and responsive UI for a smooth user experience


This project helped me deepen my understanding of Flutter UI/UX, state management, and user input handling.
